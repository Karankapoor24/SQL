Create a report to display the following results for each student.

  			The result should be Fail if a students fails in any subject irrespective of the percentage marks)
	
	*** The sequence of subjects in student_marks table match with the sequential id from subjects table.
	*** Students have the option to choose either 4 or 5 subjects only.
*/

Solution


WITH all_marks AS (
SELECT student_id, subject1 AS marks, 'S1' AS code FROM student_marks
UNION ALL
SELECT student_id, subject2, 'S2' AS code FROM student_marks
UNION ALL
SELECT student_id, subject3, 'S3' AS code FROM student_marks
UNION ALL
SELECT student_id, subject4, 'S4' AS code FROM student_marks
UNION ALL
SELECT student_id, subject5, 'S5' AS code FROM student_marks
UNION ALL
SELECT student_id, subject6, 'S6' AS code FROM student_marks
), final_data AS (
SELECT
	m.student_id, m.marks, s.id, s.name, s.pass_marks,
	CASE WHEN m.marks >= s.pass_marks THEN 0 ELSE 1 END AS fail_flag
FROM all_marks m
JOIN subjects s
ON m.code = s.id
WHERE marks IS NOT NULL
), failed_students AS (
SELECT
	student_id, 
	SUM(fail_flag) AS failed_flag,
	STRING_AGG((CASE WHEN fail_flag = 1 THEN name END), ',') AS failed_subs
FROM final_data 
GROUP BY student_id
), perc_marks AS (
SELECT
	student_id, CAST((SUM(marks) * 1.0 / COUNT(marks)) AS DECIMAL(4,2)) AS Percentage_Marks
FROM final_data
GROUP BY student_id
)
SELECT
	p.roll_no AS student_id, p.name, 
	q.Percentage_Marks,
	CASE WHEN r.failed_subs IS NULL THEN '-' ELSE r.failed_subs END AS failed_subjects,
	CASE WHEN r.failed_subs IS NOT NULL THEN 'Fail'
		 WHEN r.failed_subs IS  NULL AND q.Percentage_Marks >= 70 THEN 'First_Class'
		 WHEN r.failed_subs IS  NULL AND q.Percentage_Marks >= 50 AND q.Percentage_Marks < 70 THEN 'Second_Class'
		 WHEN r.failed_subs IS  NULL AND q.Percentage_Marks < 50 THEN 'Third_Class'
	END AS result
FROM students p
JOIN perc_marks q
ON p.roll_no = q.student_id
JOIN failed_students r
ON p.roll_no = r.student_id


Explanation 
With all_marks cte converting the subject marks data from columns to individual row.
As we get the data now in rows, comparing marks with passing marks and assigning a flag that tells whether student passed in subject or not in final_data cte
In failed_students counting in how many subject students failed and using string_agg getting the list of names of failed subject
In perc_marks simply calculating the percentage 
And finally joining distinct ctes and getting result
